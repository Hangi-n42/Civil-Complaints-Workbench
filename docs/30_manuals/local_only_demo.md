# 해당 컴퓨터에서만 사용하는 민원 시연

표준 시연은 [독립 실행 안내](local_dev_runbook.md)의 전용 설정으로 시작합니다. API와 화면은 같은 컴퓨터에서 접속합니다. API 기본 주소는 `127.0.0.1`이며, `API_HOST`에 `0.0.0.0`, `::` 또는 외부 주소를 지정하면 시작 전에 중단한다. 기존 `.env`가 전체 인터페이스 주소를 지정했다면 로컬 주소로 수정해야 한다. 개인 설정을 자동 덮어쓰지는 않는다.

자료와 API 주소를 별도로 설정해 개발할 때는 다음 명령으로 직접 시작할 수 있습니다.

```sh
python scripts/run_api.py
npm --prefix frontend run dev -- --port 3092
```

API 포트는 `API_PORT`와 화면의 `NEXT_PUBLIC_API_BASE_URL`을 맞춘다. 데이터·모델 준비는 별도 실행 절차를 따른다. 화면의 `dev`와 `start`는 `runLocalNext.mjs`에서 Next CLI를 실행하며 항상 `127.0.0.1`에 bind한다. 비로컬 `--hostname`/`-H` 인자는 거절한다. `build`는 기존 Next 빌드 명령을 유지한다.

API는 접속한 클라이언트 주소, Host와 Origin이 로컬인지 검사한다. 로컬 브라우저의 서로 다른 포트는 허용하며, 다른 웹사이트의 Origin과 비로컬 Host·접속은 변경 처리 전에 거절한다. Origin 없는 로컬 CLI 요청은 허용한다. 브라우저의 CORS 허용도 로컬 HTTP/HTTPS 주소에 한정한다.

이는 사용자 인증 기능이 아니다. 로컬의 다른 프로그램이나 사용자를 서로 분리하지 않는다. 원격 프록시·터널·포트 전달·공개 URL과 프레임워크 CLI를 직접 사용하는 별도 실행법은 이 시연 절차에서 지원하지 않는다. 외부 접속이 필요하면 데이터 조회와 변경 API의 인증·권한을 먼저 별도로 설계해야 한다.

`scripts/run_ui.py`의 과거 Streamlit 경로에도 루프백 주소 인자를 적용하지만 현재 민원 화면의 실행 기준은 `frontend`의 Next.js다. 삭제된 Streamlit 화면을 복원하거나 실행 성공으로 기록하지 않는다.

API 검사에서 사용하는 TestClient도 실제 요청과 같은 루프백 Host·클라이언트 주소를 명시한다. 제품 코드에 테스트 전용 외부 주소 예외는 두지 않는다.
